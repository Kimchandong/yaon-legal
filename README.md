# yaon-legal — YAON 이용약관 · 개인정보처리방침 게시 페이지

이 폴더는 **앱 코드와 분리된 공개용 정적 페이지**입니다. 나중에 약관 전용 공개 저장소(`yaon-legal`)로 올려 GitHub Pages로 게시합니다.

- 페이지: `ko/` · `en/` · `vi/` · `th/` · `ja/` 각 언어의 `terms.html`(이용약관 + 아동 안전 기준), `privacy.html`(개인정보처리방침 + 위치정보 안내)
- 원본: 상위 저장소 `docs/약관_초안.md` (한국어). 원본을 고치면 한국어 페이지를 다시 만들고 다른 언어도 같이 고칠 것
- 문의 이메일: yaon.support@gmail.com
- 예상 주소: `https://<계정>.github.io/yaon-legal/` → 앱은 `<주소>/<언어>/terms.html`, `<주소>/<언어>/privacy.html`을 엶

## 넣으면 안 되는 것
앱 코드, `.env`, 키·비밀번호, 서버 주소·관리 키. 이 폴더에는 HTML·CSS·이 안내 파일만 둡니다.

## 게시 전 확인
1. 법률 검토를 마치고 `[운영자 이름]`, `[관할 법원]`, `[이름·직책]`, `[시행일]` 자리를 채울 것 (4개 언어 모두)
2. 영어·베트남어·태국어·일본어 페이지는 AI 번역이므로 원어민·법률 검토를 받을 것
